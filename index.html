# Chelize's 21st — Setup Guide ## GitHub Pages (hosting) + Google Sheets (data storage) ### Both 100% free. No credit card. No Firebase. --- ## Overview of how it works ``` Guest fills in form ↓ index.html (hosted on GitHub Pages) ↓ POST Google Apps Script (acts as a tiny free API) ↓ writes Google Sheet (stores all responses) ↑ reads DJ Dashboard (reads back data on demand) ``` --- ## PART 1 — Set up Google Sheets + Apps Script ### Step 1 — Create a Google Sheet 1. Go to [sheets.google.com](https://sheets.google.com) and create a new blank sheet 2. Name it anything — e.g. **"Chelize's 21st Song Requests"** 3. Leave it open — you'll come back to it --- ### Step 2 — Open Apps Script 1. In your Google Sheet click **Extensions → Apps Script** 2. Delete all the default code in the editor 3. Open the file `Code.gs` (from this folder) and **paste the entire contents** into the editor 4. Click the 💾 Save icon (or Ctrl+S) --- ### Step 3 — Deploy the Apps Script as a Web App 1. Click **Deploy → New deployment** 2. Click the ⚙️ gear icon next to "Select type" → choose **Web app** 3. Fill in the settings: - **Description:** Song Requests API (anything is fine) - **Execute as:** Me - **Who has access:** Anyone 4. Click **Deploy** 5. Click **Authorize access** → choose your Google account → Allow 6. **Copy the Web App URL** — it looks like: ``` https://script.google.com/macros/s/AKfycb.../exec ``` You'll need this in the next step. > ⚠️ **Important:** Every time you edit Code.gs you must create a **New deployment** (not update the existing one) for changes to take effect. --- ## PART 2 — Update index.html Open `index.html` and find this line near the bottom (around line 230): ```js const APPS_SCRIPT_URL = "YOUR_APPS_SCRIPT_URL_HERE"; ``` Replace it with your URL from Step 3: ```js const APPS_SCRIPT_URL = "https://script.google.com/macros/s/AKfycbx9PbwMkIQqOtkfuv0s14_rrQl3JYNC405QyUOxe5uuDP0fTtN8it-h0fZsDb6A61sR/exec"; ``` While you're there, change the DJ PIN if you want: ```js const DJ_PIN = "2121"; // ← Change to whatever you like ``` Save the file. --- ## PART 3 — Push to GitHub and enable Pages ### Step 1 — Push your updated index.html to GitHub If you already have your repo set up: ```bash git add index.html git commit -m "Add Google Sheets backend URL" git push ``` Or upload the file directly on GitHub.com: 1. Open your repo on GitHub 2. Click on `index.html` 3. Click the ✏️ pencil (Edit) icon 4. Paste the updated contents 5. Click **Commit changes** --- ### Step 2 — Enable GitHub Pages (if not already done) 1. Go to your GitHub repo 2. Click **Settings** (top menu) 3. Click **Pages** (left sidebar) 4. Under **Source**, select **Deploy from a branch** 5. Choose **main** branch → **/ (root)** folder 6. Click **Save** 7. After a minute, your site will be live at: ``` https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/ ``` --- ## PART 4 — Test it 1. Open your GitHub Pages URL 2. Submit a test song request 3. Check your Google Sheet — a new row should appear in the "Submissions" tab 4. Click **"🎧 DJ Access"** at the bottom of the form → enter PIN `2121` 5. Dashboard should load with your test submission --- ## How to use on the night **Share the link:** - Send your GitHub Pages URL via WhatsApp group chat - On the DJ Dashboard → click **📱 QR Code** to get a QR code you can project or print **DJ workflow:** 1. Open the site → scroll to bottom → click "🎧 DJ Access" → enter PIN 2. Hit **↻ Refresh** whenever you want the latest requests 3. Use the **Top Songs** chart to see what the crowd wants most 4. Click **📥 Export CSV** to download the full list as a spreadsheet **View raw data:** - Open your Google Sheet any time to see all submissions in a plain table --- ## Checklist - [ ] Google Sheet created - [ ] `Code.gs` pasted into Apps Script and saved - [ ] Apps Script deployed as Web App (Anyone can access) - [ ] Web App URL copied into `index.html` - [ ] DJ PIN changed (optional) - [ ] `index.html` pushed to GitHub repo - [ ] GitHub Pages enabled - [ ] Test submission confirmed in Google Sheet - [ ] Link shared on WhatsApp 🎉
